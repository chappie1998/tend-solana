# Brand — Tend

_Status: active_

Tend is calm financial infrastructure for tokenized markets. The interface should feel precise, legible, and quietly premium—not like a casino.

## Palette

- Canvas: warm ivory
- Ink: near-black blue
- Accent: copper
- Positive: deep green
- Negative: muted red
- Surfaces: ivory and cool mist

## Typography

- UI and editorial headings: system sans with compact tracking
- Prices and financial data: tabular figures with a system mono stack

## Voice

Clear, compact, and honest. Explain the downside beside the upside. Never call option premium passive or risk-free yield.
